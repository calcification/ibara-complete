**Environment:** PCSX2 **v1.7.4000** Qt, built from source on Ubuntu 24.04 (Qt 6.4.2), software renderer
(`Renderer = 13`), audio off, Xvfb. BIOS SCPH-50000 v1.70 (Japan, user-supplied). User's clean ISO
SHA-256 `6e58b52a…1fb1db`; PCSX2 log: `ELF (cdrom0:\SLPM_663.01;1) Game CRC = 0x420C7FAB`.
Driven by `scripts/pcsx2_headless.py`: one profile installed as `cheats/420C7FAB.pnach` (this PCSX2
version only loads CRC-prefixed cheat files), F1 savestates every 15–30 s read offline with
`scripts/p2s_tools.py`. Raw samples: `2026-11-20_pcsx2_v1.7.4000_attract.json`.

The game boots, plays its attract demos (stage 6 garden, Porttown) and returns to the title, so all three
runs exercise real gameplay code without input. Savestate timing is wall-clock, so values from different
runs land on nearby but not identical frames.

## K02 — BLACK LABEL as a sixth Mode Select entry (baked executable, no PNACH)
Built with the other model's launcher (`research/phase04/build_menu_probe.py`, merged from
`codex/phase3-boot-validation`) and `scripts/build_ee_hooks.py --bake-elf bl_xtc`: a copy of the retail
ELF with the XTC hook image as a third `PT_LOAD` at **`0x01F00000`** and the hook site patched, installed as
`KURO.ELF`. Cheats off. Launcher retail ELF CRC `F6BD9C51`.

Bisection on the way (PCSX2 v1.7.4000): the plain retail ELF as payload works; any payload with the program
header table moved to the end of the file killed the emulator during `LoadExecPS2`, whether or not the hook
was called and wherever the segment was. Keeping the table at `0x34` and shifting all file data by `0x80`
fixed it. The cave also moved from `0x000C0000` to `0x01F00000` (zero in ~160 savestates; runtime-observed
only, may be used by modes/stages not visited).
